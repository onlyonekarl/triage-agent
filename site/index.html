Bug Fixer That Reproduces First

An AI agent that proves a crash exists before it fixes it.

The bug

average([]) divides by zero and crashes with ZeroDivisionError.

What the agent does

  1. Reads the error report.
  2. Writes a test that reproduces the crash.
  3. Runs the test and checks that it fails.
  4. Writes a fix.
  5. Reruns the tests and checks that they pass.

Result

REPRODUCED: yes
FIXED: yes. The new test and the existing tests pass.

Built with

  • CreateOS sandbox: the agent's code runs inside an isolated sandbox.
  • Stripe Projects: Supabase is set up from the command line.
  • OpenRouter: the AI model the agent calls.
